# Support

Repo Bouncer is an early prototype maintained through this GitHub repository. There is no guaranteed response time or paid support channel.

- For a reproducible defect, open a [bug report](https://github.com/Swif7ify/Repo-Bouncer/issues/new?template=bug_report.yml).
- For a proposed capability or host integration, open a [feature request](https://github.com/Swif7ify/Repo-Bouncer/issues/new?template=feature_request.yml).
- For contribution questions, see [CONTRIBUTING.md](CONTRIBUTING.md).
- For a potential security vulnerability, follow [SECURITY.md](SECURITY.md); do not post exploit details in a public issue.

When asking for help, include the operating system, Python version, agent/IDE and version, the command or setup step, and a sanitized error message. Do not paste private prompts, source code, repository paths that disclose sensitive information, access tokens, or credentials.
