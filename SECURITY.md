# Security Policy

Repo Bouncer is an early prototype. Security fixes are made against the latest source on the default branch; older releases or forks are not covered by a support commitment.

## Reporting a vulnerability

Please do not report a suspected vulnerability in a public issue. If GitHub private vulnerability reporting is enabled for this repository, use the repository's **Security** tab to submit a private report. If it is not enabled, open an issue asking for a private reporting route without including vulnerability details. GitHub documents these [private reporting steps](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/report-privately). Do not include secrets or private repository data in a report unless they are essential to reproduce the issue; redact them where possible.

There is no published response-time or remediation-time commitment. The product's current data flows, scan limits, and hook failure behavior are described in [docs/SECURITY.md](docs/SECURITY.md).
